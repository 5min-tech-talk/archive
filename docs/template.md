## 1. TL;DR
Summarize the key idea and conclusion of your talk in 2–3 lines.

## 2. Problem & Background
- What technical problem or limitation did you run into?
- Why did it matter (impact on performance, maintainability, user experience, etc.)?

## 3. Solution & Architecture
- What approach, architecture, or logic did you introduce to solve it?
- Briefly mention any alternatives you considered and why you chose this one.

## 4. Practical Takeaways
- How can teammates apply this in their own work?
- Any pitfalls, tips, or caveats worth knowing?

## 5. Glossary & FAQ
### Glossary
Define key technical terms or unfamiliar concepts mentioned in the talk.

### FAQ
List anticipated questions (e.g., "Why X instead of Y?") and brief answers.

## 6. References
List the sources referenced in this talk (docs, articles, papers, repositories, etc.).
